Przeznaczenie systemu

NEX-OMS jest wewnętrzną aplikacją wspierającą obsługę sprzedaży Multi-Click. Integracja z Allegro REST API umożliwia pracę z zamówieniami autoryzowanego konta sprzedawcy w jednym systemie OMS.

Aplikacja nie jest publiczną usługą dla innych sprzedawców. Ta strona zawiera wyłącznie informacje identyfikujące oprogramowanie; nie udostępnia panelu OMS ani danych zamówień.

Zakres integracji z Allegro

  • Autoryzacja konta sprzedawcy przez OAuth 2.0 Device Flow oraz odnawianie tokenów dostępu.
  • Podgląd i ręczny import zamówień, w tym pozycji, danych dostawy, danych do faktury, punktu odbioru i informacji o płatnościach.
  • Powiązanie numerów ofert Allegro z produktami i zestawami w katalogu OMS.
  • Odczyt szczegółów zamówienia oraz przypisanych do niego prowizji i opłat, po udzieleniu odpowiednich uprawnień.
  • Obsługa przesyłek przez moduł Wysyłam z Allegro, w tym tworzenie przesyłek, pobieranie etykiet i sprawdzanie statusu.

Obecny zakres integracji nie obejmuje wystawiania ani edycji ofert Allegro. Lokalne powiązania katalogowe nie zmieniają ofert w serwisie Allegro.

Kontakt i identyfikacja ruchu API

W sprawach dotyczących ruchu API generowanego przez aplikację NEX-OMS_device prosimy o kontakt za pośrednictwem formularza Multi-Click. W wiadomości prosimy podać nazwę aplikacji i przybliżony czas zdarzenia.

Prosimy nie przesyłać tokenów dostępu, haseł ani sekretów aplikacji.
